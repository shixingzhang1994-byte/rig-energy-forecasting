# Reserve–SOC energy-management reproducibility package

This repository contains the compact audit and reproduction package for the manuscript **“Reserve–SOC supervisory energy management for grid–diesel–battery drilling rig power systems under forecast uncertainty.”**

## Evidence boundary

The 72 h record and all evaluation holdouts were generated by one mechanistic simulator. No synchronized measurements from a target drilling rig were used. The reported conclusions are therefore limited to the specified simulated system and comparison protocol.

## Included material

- manuscript source, bibliography, figures, and compiled PDF;
- forecasting, risk, dispatch, and evaluation source code;
- experiment and controller configurations;
- the canonical simulated 72 h record and frozen forecast outputs;
- trajectory-level outputs for the ten main holdouts;
- compact intervention, V19, V20, and V21 audit evidence;
- automated tests and manuscript reconstruction scripts.

Large model weights, duplicate plots, historical development runs, caches, and raw intermediate files that are not needed to audit the manuscript claims are excluded. The V19 row-level prediction exports are stored losslessly as gzip-compressed CSV files; the manuscript audit script reads either compressed or uncompressed files.

## Environment and checks

Run commands from the repository root:

```bash
conda env create -f rig-energy-forecasting/environment.yml
conda activate qz-rig-energy-ml
python -m pytest -q rig-energy-forecasting/tests paper/experiments/tests
python paper/experiments/run_registered_extension_pipeline.py --workers 4
python paper/experiments/summarize_v19_evidential_risk.py
python paper/experiments/summarize_v21_probability_calibration.py
```

Compile the manuscript with:

```bash
cd paper/latex
latexmk -pdf -interaction=nonstopmode main.tex
```

Machine-specific absolute paths in copied text metadata were normalized to paths relative to the repository root. This packaging-only normalization does not alter reported numerical results.
